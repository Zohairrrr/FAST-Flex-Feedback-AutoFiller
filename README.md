# FAST Flex Auto-Filler

A lightweight Chrome Extension that automatically fills out the mandatory course and lab feedback forms on the FAST-NUCES Flex Student portal.

## Features
- Context-aware: Detects whether you are filling out a Theory or Lab feedback form.
- One-click auto-fill: Instantly selects the highest rating across all categories.
- Pre-fills the comment boxes with randomized, context-appropriate feedback.
- Optimized to run smoothly with the Flex portal's backend.

## How to Install (For Chrome/Brave/Edge)

1. Download this repository by clicking the green **`<> Code`** button above and selecting **Download ZIP**.
2. Extract the ZIP file to a folder on your computer.
3. Open your browser and go to the extensions page:
   - Chrome/Brave: `chrome://extensions/`
   - Edge: `edge://extensions/`
4. Turn on **Developer mode** (usually a toggle in the top right corner).
5. Click the **Load unpacked** button.
6. Select the folder you extracted in Step 2.

## How to Use
1. Log into Flex and go to the **Course Feedback** section.
2. Click **Give Feedback** for any course.
3. Click the extension icon in your browser toolbar and hit **Fill Form**.
4. Verify the details, scroll down, and manually click **Submit**.
